# vnmax-render

Scripts e pacotes de render dos documentarios dos paises (Bitcoin VNMAX). Os pacotes ficam nos releases.

- `colab_<PACOTE>.ipynb`: abra no Colab e "Executar tudo". Sem Google Drive: cada capitulo pronto e enviado ao receptor da maquina de casa.
- `tunel.txt`: URL atual do receptor (atualizada sozinha quando o tunel muda). A chave nela so autoriza enviar video para uma pasta isolada; nao e credencial de conta.
